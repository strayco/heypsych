After:
```json

  "seo": {
    "description": "Comprehensive guide to Alprazolam (Xanax)...",
    "canonical": "https://www.heypsych.com/treatments/alprazolam-xanax",
    "no_index": false
  }
  // schema_injection removed - auto-generated by SchemaFactory
}
```

### 4. Schema Architecture ✅

**How It Works Now:**

Your code **already generates separate, optimized schemas** via [SchemaFactory.generateAll()](../src/lib/seo/schema-factory.ts):

```typescript
// Automatically generates 5-6 schemas per treatment page:
const schemas = [
  buildDrugSchema(entity),           // 1. Drug node (@id: #drug)
  buildMedicalWebPageSchema(entity), // 2. MedicalWebPage node (@id: #webpage)
  buildBreadcrumbSchema(entity),     // 3. BreadcrumbList
  buildMedicalReviewBoardSchema(),   // 4. Organization (review board)
  buildDefaultReviewBoardPersonSchema(), // 5. Person (reviewer)
  buildFAQPageSchema(entity),        // 6. FAQPage (if FAQs exist)
];
```

**Each schema has proper @id references:**
- Drug: `/treatments/alprazolam-xanax#drug`
- WebPage: `/treatments/alprazolam-xanax#webpage`
- FAQ: `/treatments/alprazolam-xanax#faq`

**FAQs extracted from JSON:**
```typescript
// FAQ builder reads from entity.faqs or entity.faq
const faqs = entity.data?.faqs || entity.data?.faq;
```

**Result:** Google-friendly separate schema nodes in a single `@graph`.
